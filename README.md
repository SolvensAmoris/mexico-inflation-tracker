# Mexico Inflation Tracker | INPC - Banxico / INEGI

> WE DON'T NEED MORE EXPLANATIONS. WE NEED EVIDENCE.

Reproducible monthly INPC pipeline and Power BI project.

## Data source
- Banxico SIE cuadro CP154: Principales índices mensuales.
- Series SP1: general monthly INPC index.
- Banxico SIE REST API; token passed in the `Bmx-Token` header.
- INEGI has held the exclusive legal authority to prepare and publish national price indices since July 2011; Banxico SIE distributes the series.

## Pipeline
1. Bronze: `notebooks/01_Bronze_Ingestion.py` downloads SP1 into `data/bronze/inpc.csv`.
2. Silver: `notebooks/02_Silver_Transformation.py` validates dates, numeric values and uniqueness.
3. Gold: `notebooks/03_Gold_Aggregation.py` creates `Fact_INPC` and `Dim_Date` CSV outputs.
4. Power BI: `powerbi/Mexico-Inflation-Tracker.pbip` contains the semantic model and report scaffold.

## Run
Set the token locally; never commit it:
```bash
export BANXICO_TOKEN="YOUR_TOKEN"
python notebooks/01_Bronze_Ingestion.py
python notebooks/02_Silver_Transformation.py
python notebooks/03_Gold_Aggregation.py
```

See [powerbi/README.md](powerbi/README.md) for opening the PBIP and saving the native PBIX.

## Evidence and limits
The previous `data/raw/CP154.csv` contained an HTML page, not CSV observations. It has been removed rather than treated as data. No INPC values are fabricated. First refresh requires a valid Banxico SIE API token.

The PBIP is a text-based project. A native `.pbix` binary must be generated by Power BI Desktop using **File > Save as**.
