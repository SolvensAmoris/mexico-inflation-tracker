# Power BI project

Open `Mexico-Inflation-Tracker.pbip` in Power BI Desktop.

## First refresh

1. Obtain a Banxico SIE API token from the official SIE API portal.
2. In Power BI Desktop, open **Transform data > Manage parameters**.
3. Set `BanxicoToken` to your token. Do not commit the token or embed it in source files.
4. When prompted, configure the Web data source credentials/privacy level and refresh.
5. Save the project. Use **File > Save as > Power BI Desktop (.pbix)** to produce the native binary deliverable.

## Report page

The PBIR report includes three KPI cards and a monthly INPC line chart, using the StarkCore black-and-gold theme. The report page is **Mexico Inflation Overview**.

## Model

- `Fact_INPC`: monthly general INPC index, series SP1.
- `Dim_Date`: contiguous calendar table generated from the fact date range.
- Relationship: `Dim_Date[Date]` (one) to `Fact_INPC[Fecha]` (many).
- Measures: `INPC_Actual`, `INPC_AñoAnterior`, `Inflacion_YoY`, `INPC_Promedio3M`.

`INPC_Actual` returns the latest available observation in the current date context, not the sum of the entire index history. `INPC_Promedio3M` averages the latest three available monthly observations. `Inflacion_YoY` is formatted as a percentage.

## Provenance

The former `data/raw/CP154.csv` was HTML, not CSV, and was removed. The reproducible Python pipeline downloads the official Banxico SIE API series using `BANXICO_TOKEN`. The Power BI model uses the same API directly through the `BanxicoToken` parameter.

The PBIP is source text, not a PBIX. A native PBIX must be generated by opening and saving this project in Power BI Desktop.
