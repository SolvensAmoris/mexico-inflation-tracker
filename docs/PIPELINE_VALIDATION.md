# Pipeline validation and live refresh

## Offline regression tests

The repository includes an offline regression suite. It uses synthetic fixtures only and never claims those fixtures are official INPC observations.

Run locally with:

```bash
python -m unittest discover -s tests -v
```

GitHub Actions runs the same checks on pushes, pull requests, and manual dispatch. The checks validate sorting, numeric normalization, duplicate-date rejection, the fact table, and the contiguous date dimension.

## Live Banxico refresh without a local terminal

The **Refresh official INPC data** workflow can be started from GitHub's Actions tab and also runs monthly. It downloads Banxico SIE series SP1, validates Bronze -> Silver -> Gold, and publishes the four CSV outputs as a 90-day workflow artifact.

One-time setup in GitHub's web interface:

1. Open the repository's **Settings**.
2. Select **Secrets and variables > Actions**.
3. Create a repository secret named `BANXICO_TOKEN`.
4. Paste the Banxico SIE API token as its value and save.

Then open **Actions > Refresh official INPC data > Run workflow**. The token is injected as a secret environment variable; it is not printed, written into the repository, or included in the artifact. The generated CSVs are downloadable from the successful workflow run under **Artifacts**.

The offline CI workflow does not need this secret and never calls the live API. A live refresh is not considered successful until the refresh workflow itself completes successfully.

## Power BI binary boundary

The PBIP is a text-based Power BI project. A native `.pbix` binary must still be generated by opening the PBIP in Power BI Desktop, refreshing with the Banxico parameter, and using **File > Save as > Power BI Desktop (.pbix)**. The Android/UserLAnd environment cannot produce that native binary.
